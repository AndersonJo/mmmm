04. nn.Module + Linear 🧱
← → 방향키 / 슬라이더로 체험

nn.Module + Linear

파라미터를 묶고 forward를 정의하는 표준

왜 모듈화가 필요한가

비유: 레고 블록. 각 모듈이 자기 파라미터/forward를 알면 전체가 자동 학습.
  • 파라미터 모으기 — model.parameters() 한 번에
  • state 저장/로드 — state_dict()
  • device 이동 — model.to('cuda')
  • 학습/평가 모드 — train() / eval()
💡 nn.Module 안 쓰면 위 편의 0%.

Linear: y = xWᵀ + b

x: (N, D1) W: (D2, D1) ← PyTorch 관행 b: (D2,) y = x @ W.T + b shape (N, D2)

총 파라미터 = D1·D2 + D2 = D2·(D1+1)

파라미터 수: 15

weight/bias 슬라이더로 직선

1D Linear: y = w·x + b. 학습 = w, b 조절해 데이터에 맞추기.

RMSE: 1.23

  • w = 기울기, b = y절편
  • nn.Linear 1개 → 직선 회귀까지

💡 비선형(활성화) 없으면 층을 쌓아도 결국 직선.

nn.Module 구조

class MyMLP(nn.Module): def __init__(self): super().__init__() self.fc1 = nn.Linear(4, 16) self.fc2 = nn.Linear(16, 3) def forward(self, x): h = torch.relu(self.fc1(x)) return self.fc2(h) m = MyMLP() out = m(torch.randn(2, 4)) # m(x) → m.forward(x)
  • __init__: sub-module 등록
  • forward: 텐서 흐름 정의
  • m(x)는 자동으로 m.forward(x) 호출

저장/로드.

💡 Buffer(학습 안 되는 상태)는 register_buffer — BN의 running_mean이 대표.

Sequential vs Custom Module

nn.Sequential (간단)

m = nn.Sequential( nn.Linear(4, 16), nn.ReLU(), nn.Linear(16, 3), )

✓ 짧고 명확

✗ 분기/skip 불가

Custom subclass

class Res(nn.Module): def __init__(self): super().__init__() self.f = nn.Linear(4,4) def forward(self, x): return x + self.f(x) # ← skip!

✓ 자유로운 흐름

💡 Transformer/ResNet 등 대부분 Custom 형태.

가중치 초기화

  • Xavier (Glorot): Var = 1/fan_in — sigmoid/tanh
  • He (Kaiming): Var = 2/fan_in — ReLU
  • Uniform/Normal: 단순 랜덤

가중치 표준편차: 0.18

왜 He가 ReLU에 맞나?

ReLU는 절반이 0 → 출력 분산이 절반으로. 입력 분산을 2배 키워야 출력 분산 보존.

Var(W) = 2 / fan_in # He Var(W) = 1 / fan_in # Xavier
  • ReLU + Xavier → 깊을수록 활성값 작아짐 (vanishing)
  • ReLU + He → 안정 — 100층 ResNet도 학습
  • Zero init은 모든 뉴런 동일 학습 → 망함
💡 ResNet 논문: "초기화 하나로 학습률 0.1까지 가능"

Composition: 모듈 안의 모듈

class Net(nn.Module): def __init__(self): super().__init__() self.blocks = nn.ModuleList( [Block(64) for _ in range(4)]) def forward(self, x): for b in self.blocks: x = b(x) return x
  • nn.ModuleList — list처럼, 자동 등록
  • nn.ModuleDict — dict 버전
  • 일반 list → 파라미터 등록 안 됨!

실전: MNIST 분류기

class Classifier(nn.Module): def __init__(self): super().__init__() self.net = nn.Sequential( nn.Flatten(), nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 128), nn.ReLU(), nn.Linear(128, 10), ) def forward(self, x): return self.net(x)

총 ~118K 파라미터. MacBook 1분이면 학습.

💡 다음 모듈에서 이 모델로 MNIST 학습.

흔한 실수

1. super 빼먹음

→ AttributeError

2. 일반 list로 layers

→ ModuleList 써야 함

3. forward에 inplace

→ x = x.relu()

4. m.forward(x) 직접 호출

hooks 안 불림. 항상 m(x).

5. eval() 안 부르고 추론

Dropout/BN 학습 모드.

6. .to(device) 순서

모델 먼저, optimizer 나중.
