왜 딥러닝 프레임워크가 필요한가?

비유: 자동차 vs 부품 직접 깎기

NumPy로 신경망을 짜는 건 엔진을 직접 깎는 것. 프레임워크는 미리 만들어진 고성능 부품 + 자동 변속기(autograd)를 줍니다.

  • 🧠 자동 미분 (autograd) — 손으로 ∂L/∂W 계산 안 함
  • 🚀 GPU/TPU 가속 — CUDA 커널 자동 호출
  • 🧱 모듈화된 계층 — Linear, Conv, LSTM 즉시 사용
  • 📦 데이터 파이프라인, 분산 학습, 양자화 등 풀스택
💡 직접 코딩하면 ResNet50 한 번 돌리는 데 수 천 줄. PyTorch면 30줄.

프레임워크 타임라인 — 연도 슬라이더

슬라이더로 연도를 바꾸면 그 시점의 지배적 프레임워크와 사건이 표시돼요.

PyTorch 0.1 발표

Facebook AI Research가 Lua 기반 Torch를 Python으로 재구현. 동적 그래프 채택.

💡 2018년경 학계 점유율이 TF→PyTorch로 역전 (NeurIPS/ICML 논문 기준).

정적 그래프 vs 동적 그래프

두 모드의 차이는 그래프를 언제 만드는가입니다. 토글로 같은 코드의 흐름을 비교하세요.

입력 길이 n = 3

y = x for i in range(n): y = y * 2 + 1 loss = (y - target)**2

💡 동적이면 매 iteration 그래프가 n에 따라 늘어나도 자동으로 새로 그려집니다.

Eager vs Graph 트레이드오프

Eager (즉시 실행)

✓ 디버깅 쉬움 — print, pdb 그대로

✓ 파이썬 제어 흐름(if/for) 자유

✗ 그래프 최적화 제한

✗ 배포가 약간 까다로움

PyTorch 기본 모드

Graph (사전 컴파일)

✓ XLA/TensorRT 최적화

✓ TPU/모바일 배포 유리

✗ 디버깅 까다로움

✗ 동적 shape 어려움

JAX, TF graph mode

하이브리드 (요즘 트렌드)

✓ torch.compile() (PyTorch 2.0+)

✓ tf.function

✓ 디버깅은 eager, 배포는 graph

2026 표준

PyTorch 2.x: model = torch.compile(model) # 한 줄로 30~80% 속도 향상

Hello, PyTorch — 30초 데모

import torch x = torch.tensor([1., 2., 3.], requires_grad=True) y = (x ** 2).sum() y.backward() print(x.grad) # tensor([2., 4., 6.])
  • Tensor — N차원 배열 (NumPy + GPU + 미분)
  • requires_grad — 이 텐서를 추적해 줘
  • backward() — 자동 미분 트리거
  • .grad — 계산된 ∂y/∂x
💡 이게 PyTorch의 90%. 나머지는 이걸 모듈로 묶고 데이터를 흘려보내는 일.

핵심 객체: Tensor 한 줄 요약

torch.tensor(데이터, dtype, device, requires_grad)
  • 데이터 — 리스트/NumPy/스칼라
  • dtype — float32(기본), float16, int64, bool …
  • device — cpu / cuda / mps
  • requires_grad — autograd 추적 여부
x = torch.randn(3, 4, device="mps", dtype=torch.float32) print(x.shape, x.device, x.dtype) # torch.Size([3, 4]) mps:0 torch.float32

자동 미분 미리보기

딥러닝의 핵심은 결국 "손실에 대한 파라미터 미분". PyTorch는 이걸 자동으로 해줘요.

w = torch.tensor(2.0, requires_grad=True) loss = (w*3 - 6) ** 2 # = (3w - 6)² loss.backward() w.grad # = 2·(3w-6)·3 = 0 (w=2)

loss = 0.00 · dL/dw = 0.00

💡 학습 = "w를 살짝 옮기면 loss가 줄어드는 방향"을 grad에서 바로 읽음.

흔한 오해 Q&A

"PyTorch가 NumPy보다 느린 거 아닌가요?"

CPU 단일 스레드에선 비슷. 하지만 GPU에선 10~100배. 또 자동 미분은 NumPy엔 없죠.

"동적 그래프는 항상 느린가요?"

아니요. torch.compile()로 graph 캡처해 XLA/TorchInductor가 정적 그래프와 동등하게 가속.

"모델 배포는 어떻게?"

torch.jit.script, torch.export, ONNX, TorchServe, vLLM 등 단계별 옵션.

"한국어 모델도 되나요?"

네. skt/kogpt2-base-v2(이번 강의 마지막 노트북 15)는 PyTorch 가중치로 제공됩니다.

💡 PyTorch는 "학습부터 서빙까지" 한 도구로 가능한 거의 유일한 종합 생태계.
